# inventory/ · 每周盘点产出

由技能 `toolbelt-scan`（SSoT：[xingtu-skills](https://github.com/xingtu1996/xingtu-skills)）每周一 10:00 自动扫描生成，
定时任务定义见 `../automations/toolbelt-weekly-scan.yaml`。

## 文件口径

| 文件 | 内容 | 用途 |
|---|---|---|
| `toolbelt_inventory.json` | 全量机器可读台账（工具矩阵/技能安装/漂移/僵尸/汇总） | 增量对比基准，每周覆盖 |
| `<日期>.html` | 当周单文件看板（KPI + 矩阵 + 漂移 Top + 僵尸） | 人读，历史留存 |

## 脱敏口径（公开的前提）

- 绝对路径一律泛化（`/Users/<user>/` → `~/`）
- 凭据类目录（脚本内置敏感模式识别）仅记存在，不列内容
- 含红线词（身份/雇主代号/凭据类）的技能名与目录名**只计数不列名**
- 会话正文从不读取，只统计数量/大小/时间
- 输出全文过 30 词红线表，**0 命中才落盘**（脚本内置，命中即拒写）
