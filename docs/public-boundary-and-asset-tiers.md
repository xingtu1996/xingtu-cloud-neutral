# 公开边界与资产分级（制度版）

本页是行途内容与资产的公开边界制度（框架公开版）。只写分级框架与原则；具体的核心资产清单与红线细节属私有层，存放在私有 vault，不在本页展开——这本身就是本制度的第一条示范：制度可以公开，清单不公开。

## 一、为什么要分级

多 Agent 协作与多平台分发下，内容一旦流出就收不回。分级的目的不是保守，而是让每一次公开都是有意识的选择：公开什么换信任与影响力，保留什么守住积累与安全，先定级、再存放、后发布。

## 二、四级框架

| 级别 | 定义 | 流转范围 |
|---|---|---|
| L0 公开 | 可上公网、可被引用 | 公开仓、公众号、个人站、公开平台 |
| L1 脱敏后公开 | 去标识、去关键参数，只给结论与证据摘要后可公开 | 同 L0，发布前过脱敏检查 |
| L2 私有 | 只在私有仓与本地流转 | 私有仓、本地文件 |
| L3 禁区 | 永不落公网；凭证类连私有仓明文也不进 | 安全存储，只记存放位置不记值 |

判定总则：拿不准时就高不就低；任何协作者不得自行降级。

## 三、分类原则（只写原则，不写清单）

- **身份**：对外只用统一署名与公开标签；真实身份信息属禁区。
- **内容**：已发布的可公开；未发布的草稿、选题与排期属私有；声明原创的稿件全文不上公网站点，只放摘要引流。
- **数据**：结论级数字可公开换信任（附口径说明）；全量与连续序列属私有——数据的价值在连续性，公开结论不公开序列。
- **方法与工具**：开源版负责获客与立信，可公开；内部完整版负责交付，属私有，两者物理隔离。
- **商业**：未正式发布的报价、合作与客户信息属私有；雇主内部信息零出境，无例外。
- **凭证**：密码、密钥、验证码、会话令牌属禁区，只走安全存储，任何文档只记存放位置。

## 四、护城河的一般形态

真正的护城河靠时间与真实积累，无法被一次性抄走：连续的真实数据、真实项目的案例沉淀、协作体系的运行记录、个人品牌的信任、以及内部完整版的交付能力。公开的永远是结论、框架与证据摘要，积累本体留在私有层——公开是为了让积累被看见，不是把积累本身交出去。

## 五、与中央大脑的关系

分级是记忆层的访问规则：记忆层（全局迭代与动机）中理念与战略转向可整理公开，运行记录与全量数据留在私有层；工程层按仓的公开/私有属性天然分级；驱动层（任务台）整体私有。先有分级，共享才安全。
